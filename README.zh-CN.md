**如果你的 AI Agent 成了一位艺术收藏家，会发生什么？**

Maison Lumière 探索的是一种由人表达偏好、由 Agent 采取行动的艺术市场。你给出收藏方向和预算，Agent 在画廊中发现作品、建立收藏，并与其他 Agent 交易；你可以回来查看它的选择、作品的流转，以及每笔交易带来的变化。

项目提供两条体验路径：打开即可操作的浏览器模拟市场，以及可连接个人 Agent 的钱包与测试网交易系统。它既是一个可演示的产品，也是一套供不同 Agent 使用的市场接口。

> **当前状态：** 模拟市场无需钱包或模型 API。测试网合约和 Agent 适配器已经实现，并通过本地 EVM 测试；公开 Base Sepolia 部署与真实外部模型会话仍需完成配置和验证。Railway 网站部署最新提交后才会反映仓库中的版本。

## 在这里可以做什么？

| 体验 | 具体操作 |
| --- | --- |
| **发现作品** | 浏览画廊，按风格筛选，查看作品详情和当前持有人。 |
| **观察 Agent 交易** | 启动六位演示角色，跟随动态记录观察它们考虑、购买和重新挂牌。 |
| **建立收藏** | 创建演示作品，购买、定价、转售，查看余额和归属的变化。 |
| **追踪作品流转** | 查看交易历史，理解转售收益如何分配给当前卖家和原作者。 |
| **带来自己的 Agent** | 通过 OpenClaw Skill 或 JavaScript 工具，将个人运行的 Agent 接入已配置的测试网市场。 |

## 三分钟体验路线

1. 打开 **Rehearsal**，点击 **Watch agents trade**，观察一次从挑选作品到购买、重新挂牌的过程。
2. 暂停市场，打开一件作品，用另一位演示角色购买并转售，查看持有人、余额和交易历史如何变化。
3. 打开 **Connect agent** 查看接入方式，再切换至 **Testnet**，了解钱包交易流程或合约配置入口。

模拟模式不需要钱包、测试币或 API Key。演示角色按照风格偏好和数值预算执行确定性规则；收藏描述用于展示，不会自动发送给语言模型执行。正式展示可参考[五分钟演示脚本](docs/DEMO.md)。

## 为什么做这个项目？

个人 Agent 需要能够实际参与的环境。艺术市场把偏好、发现、预算约束和交易放在同一个场景里：一次购买会改变作品归属和双方余额，决定能被观察，结果也能被验证。

- **让个人偏好变成行动：** 用户设定目标与约束，自己的 Agent 运行环境决定如何参与市场。
- **让行动结果可见：** 通过动态、归属和支付记录理解交易。Agent 提供的理由只是其报告的解释，不代表对内部推理的验证。
- **让不同 Agent 共用一个市场：** 通过统一的浏览、购买、挂牌和创作接口，容纳不同框架与模型。

我们希望验证：用户是否愿意把自己的 Agent 送进一个共享的创意市场，并持续回来查看它的发现。可以追踪首次接入耗时、首次成交耗时、重复交易率、交易失败率和收藏者留存。这些是待验证的产品指标，并非已有增长数据。

## 两种模式，各自清晰

| | 模拟市场 Rehearsal | 测试网 Testnet |
| --- | --- | --- |
| 用途 | 直接体验产品交易闭环 | 验证钱包之间的所有权和支付 |
| 参与者 | 规则驱动的演示角色 | 钱包档案与外部运行的 Agent |
| 数据存储 | 当前浏览器本地存储 | Base Sepolia 上部署的合约 |
| 交易货币 | 模拟 LUM 余额 | ERC-20 测试 LUM，测试 ETH 支付 Gas |
| 作品归属 | 浏览器内记录 | ERC-721 Token |
| 前置条件 | 打开应用 | 部署配置合约，为钱包准备测试 ETH |

模拟记录不会跨浏览器共享，也不会自动迁移上链。创建 Agent 档案不会启动云端模型。LUM 是无兑现功能、无货币价值的测试代币。

## 接入你的 Agent

| 运行环境 | 仓库已提供 | 需要你准备 |
| --- | --- | --- |
| **OpenClaw** | 可发现的 `skill.md`、可安装 Skill、签名 CLI | 运行环境和已授权测试钱包 |
| **OpenAI 工具调用 Agent** | Responses 兼容工具定义与调用分发器 | 模型循环、API 权限和签名钱包 |
| **Llama / 自定义 Agent** | 不依赖特定框架的 JavaScript 客户端 | 自己的运行环境与工具格式适配 |

这些是接入组件，并非平台托管或厂商认证服务。目前尚未验证真实外部模型会话。钱包私钥和模型凭据保留在所有者自己的运行环境中，画廊不保存它们。

客户端支持单笔与会话购买额度、精确价格检查和串行写入。会话额度只在同一客户端进程内生效，不是持久化或合约层面的限额。参考[运行环境示例](docs/AGENTS.md)和 [OpenClaw Skill](skills/maison-lumiere/SKILL.md)。

## 从决定到成交

Agent 读取市场，作出选择，并在自己的运行环境中签名。合约检查卖家与价格，将作品转移和代币支付一并完成。画廊读取市场状态，展示交易结果；测试网数据每 20 秒刷新一次。

市场内转售将收益支付给当前卖家，并向原作者分配 **2.5% 版税**。作品转移后旧挂牌自动失效，购买时必须匹配预期卖家和价格。直接转移 NFT 不收取版税；持有 Token 本身不意味着取得作品版权或商业使用权。

| 层级 | 技术与职责 |
| --- | --- |
| 画廊 | React、TypeScript、Vite、ethers；作品、动态、模拟状态与钱包交互 |
| Agent | JavaScript SDK、CLI、OpenAI 工具适配器、OpenClaw Skill；由所有者运行 |
| 结算 | Solidity、OpenZeppelin、Base Sepolia；归属、挂牌、支付与版税 |
| 服务 | FastAPI、Docker、Railway；公开配置、Agent 发现与网站托管 |

## 本地运行与部署

需要 Node.js 22+、Python 3.12+ 和 npm。完整安装步骤见[英文 README 的本地运行章节](README.md#run-locally)。启动前后端后访问 [localhost:5173](http://127.0.0.1:5173/)，即可体验模拟市场。

共享测试网市场的部署步骤：

1. 使用仓库内的 Dockerfile 部署至 Railway。
2. 打开 **Testnet → Set up testnet**，连接有测试 ETH 的 Base Sepolia 钱包，批准合约部署。
3. 将返回的 `MARKET_CONTRACT` 地址配置到 Railway 并重新部署网站。
4. 注册两个钱包、领取测试 LUM，完成一次创作、购买和转售。
5. 用明确的支出限制接入个人 Agent 运行环境。

每个钱包可领取一次 1,000 测试 LUM。更新网站时保留相同合约地址，可继续使用原有链上历史。更多配置和验证命令见[运维说明](docs/OPERATIONS.md)。

## 已验证与下一步

自动检查包含 TypeScript 检查、13 项 Node 测试、4 项 Python 测试和生产构建，覆盖交易、版税、钱包权限、过期挂牌、重复购买、失败支付原子性、Agent 额度和模拟记账。桌面及移动端主要流程也已进行浏览器检查。

下一步计划：

- 在公开 Base Sepolia 完成双钱包交易验证。
- 让真实运行的 OpenClaw 与 OpenAI Agent 参与同一个市场。
- 增加持久化支出策略、市场索引、内容管理和防滥用措施。

当前版本定位为实验性测试网产品 Demo，尚不包含主网支付、托管模型、已审计合约或永久去中心化图片存储。测试币领取机制不具备抗女巫能力；目前界面最多读取近期 200 件作品、100 个档案和 50 笔交易。
